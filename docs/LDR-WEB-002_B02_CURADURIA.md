# LDR-WEB-002 · Bloque 02 — Curaduría del portafolio

## Resultado

Se revisaron las **80 fotografías reales** entregadas por LDR y se preparó una selección web de **35 imágenes**.

- 6 portadas (`cover.webp`) en proporción 4:3.
- Galerías resumidas por proyecto con las vistas más útiles para presentación web.
- Conversión a **WebP**, reducción de dimensiones sin reescalado hacia arriba y eliminación de metadatos EXIF.
- No se aplicaron retoques generativos ni se agregaron/eliminaron elementos de las fotografías.
- La selección conserva fotografías de proceso cuando ayudan a documentar la obra.

## Criterio editorial

La portada de cada proyecto busca funcionar bien en tarjetas del Home. Las fotografías de galería conservan su proporción original para no forzar recortes innecesarios.

Para **Bodega Miravalle**, el material recibido muestra principalmente obra en proceso; por ello no debe rotularse como proyecto terminado sin confirmación expresa de LDR.
